
## 执行服务提示与启动边界（2026-10-21）

Agent 版本和 Benchmark 页面新增“执行服务”提示，每 5 秒读取一次数据库中现有 worker 独占连接锁：检测到连接、未检测到连接、读取失败/尚未确认分别展示。它不是心跳或健康检查：连接存在不保证任务推进，也不表示允许模型调用。断线后数据库释放连接锁可能有延迟。校验排队时“最近校验”显示“校验已提交，尚无已完成的校验结果”，不再误写“未校验”。任务仍可入队，前端不会自动启动 worker 或重复提交。

当前本机开发环境：每次启动整套平台时启动一次 worker，并保持运行；每次刷新网页、登记 Agent 或点校验都不需要重新运行脚本。关闭 worker 或重启电脑后需要重新启动。正式部署应由服务管理器负责启动和维护 worker，普通用户只操作网页。当前 docker-compose.yml 没有 worker 服务，因此不能声称 docker compose 已实现全平台自动启动；本轮未安装开机任务、后台守护或改变模型授权策略。
